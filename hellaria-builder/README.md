# Hellaria Builder Wand — mod Horizon

Mod natif Horizon pour la baguette de bâtisseur du serveur Hellaria :

- **Aperçu** : contours verts des blocs que la baguette va poser (orange au-delà de ce que contient le sac).
- **Maj + clic droit** : écran de mélange du sac (curseurs 0 à 100, Appliquer / Annuler).
- **Maj + clic gauche** : bascule horizontale / verticale.

Il faut le serveur Hellaria avec `hellaria-bridge` 2.2.0 ou plus. Sans ce mod, les joueurs Horizon
gardent le menu coffre du serveur.

## Installation

Compiler avec le lanceur Horizon (la première fois ~20-30 min) :

    horizon-launcher native-build <ce dossier> --trust-native-code

Testé sur Horizon Nightly 2026-11-13 (9f42064).
